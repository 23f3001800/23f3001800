### [TraceRoot](https://github.com/23f3001800/TraceRoot)

clean end-to-end staging recovery and production promotion are still open work.

### [DevDocs AI](https://github.com/23f3001800/DevDocs-AI)
A RAG application for repositories, documentation, and PDFs. It combines BM25
and dense retrieval, supports reranking, and streams answers with source paths.
I’m improving the evaluation so each result can be traced to the exact context
and configuration used to generate it.

Music genre classification with an Audio Spectrogram Transformer. The project

of 0.8871 across 10 genres. The model and inference demo are linked in the repo.
